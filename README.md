# Ananthakrishnan A K — Portfolio website

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## View it on your computer
1. Download and extract the ZIP.
2. Open `index.html` in Chrome, Edge, or another browser.
3. Keep the three files (`index.html`, `styles.css`, `script.js`) together in the same folder.

## Publish it with GitHub Pages
1. Create a new public repository on GitHub (for example: `portfolio`).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository's root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide a public website address after publishing.
